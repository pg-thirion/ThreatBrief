# Security policy

ThreatBrief is an advisory-only public-feed reader. The server accepts no organisation data, credentials, arbitrary source URLs or model prompts. Browser profiles are not encrypted and must not contain secrets or confidential identifiers. Use a dedicated browser profile on shared devices. CLI inventories and reports belong on restricted local storage.

Report vulnerabilities privately to the repository maintainer via GitHub private vulnerability reporting if enabled. Do not publish exploit details or real organisation data in public issues.

Deployment owners must configure HTTPS, access controls where appropriate, upstream rate limits, dependency/image scanning and incident monitoring. Do not connect automatic remediation to unverified product matches.
